# قالب إيليت — لوحة تحكم إدارية عربية RTL جاهزة للبيع

> **Elite Admin Dashboard — Premium Arabic RTL Admin Template**
> لوحة تحكم عصرية بخط Cairo، رسوم Chart.js، وضع ليلي محفوظ، وجدول طلبات تفاعلي — بدون أي إطار عمل ثقيل.

عرض حي مباشر: https://ehabgx126.github.io/elite-admin-dashboard/

---

## لماذا لوحات التحكم؟

قوالب لوحات التحكم هي **الأكثر ربحية في فئة القوالب الرقمية** عالميًا (مصادر 2025-2026)، لأن كل متجر إلكتروني وكل شركة تحتاج واجهة إدارية. هذه النسخة عربية RTL بالكامل — فئة نادرة ومرغوبة في السوق الخليجي.

## المميزات

- **RTL و LTR**: عربي بالكامل، وجاهز للتحويل للإنجليزية بتبديل `dir` في وسم html
- **وضع ليلي/نهاري** مع حفظ اختيار المستخدم في localStorage
- **رسوم Chart.js 4**: رسم خطي للمبيعات (أسبوعين للمقارنة) + رسم دائري لتوزيع الفئات، ويعيد تلوين نفسه تلقائيًا عند تبديل الوضع
- **4 بطاقات إحصائيات** بعدّادات متحركة بأرقام عربية
- **جدول طلبات** بشارات حالات (مكتمل / قيد التنفيذ / ملغي) + بحث فوري من الشريط العلوي
- **قائمة جانبية** قابلة للطي على الجوال مع خلفية معتمة
- **تصميم متجاوب** حتى 320px + متغيرات ألوان مركزية في `:root`
- **كود نقي** HTML/CSS/JS بدون إطارات — سريع وسهل التخصيص والتسليم

## التشغيل محليًا

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

(الفتح المباشر للملف يعمل أيضًا — الرسوم تُحمّل من CDN)

## دليل التخصيص (للمشتري)

| ماذا تريد تغييره؟ | أين؟ |
|---|---|
| الألوان الرئيسية | متغيرات `:root` في `css/style.css` (`--primary` وغيرها) |
| الوضع الليلي | متغيرات `[data-theme="dark"]` في نفس الملف |
| بيانات الرسوم | مصفوفة `data` داخل `js/main.js` (القسم 4) |
| صفوف الطلبات | `<tbody>` داخل `index.html` — كل صف `<tr>` مستقل |
| عناصر القائمة الجانبية | قسم `sidebar-nav` — انسخ أي `nav-item` وأعد تسميته |
| اسم المنتج والشعار | قسم `sidebar-brand` |

## التحويل إلى LTR (إنجليزي) بثلاث خطوات

1. في `index.html`: بدّل `<html lang="ar" dir="rtl">` إلى `<html lang="en" dir="ltr">`
2. استبدل خط Cairo بخط Inter في رابط Google Fonts
3. ترجم النصوص — التنسيق يتكيف تلقائيًا (خاصية `inset-inline` مستخدمة في كل الملف)

## فكرة الإصدار التجريبي المجاني (Demo)

ارفع النسخة الحية عبر GitHub Pages (دقيقة واحدة): Settings → Pages → فرع `main` → `/root`. أضف الرابط في صفحة البيع — العرض الحي يرفع التحويل بشكل ملحوظ.
